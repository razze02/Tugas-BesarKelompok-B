# Tugas-BesarKelompok-B
Liga.in merupakan aplikasi manajemen turnamen e-sports dengan relasi banyak-ke-banyak antara turnamen dan tim. Hasil setiap laga dicatat guna menyusun klasemen. Data partisipasi tim dikelola memakai Multi Linked List, sementara data pertandingan beserta hasilnya disimpan dalam Binary Search Tree.
